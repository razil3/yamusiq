# yamusiq

## Где настоящий интерфейс

**Единственная версия репозитория и есть настоящий продукт**: ветка `master`,
единственный коммит `5e75958` (осиротевшая точка отсчёта, история до неё
удалена). Здесь живой TUI с плеером: визуализатор из реального FFT-спектра,
панель `Frequencies` (32 Hz … 16 kHz), очередь `Likes`, `Track data` с
качеством `FLAC · lossless`, `Signal level`, `Track progress`, `Volume`,
строка статуса с хоткеями `? help · Tab focus · y lyrics · i lang · q quit` и
блок бренда `y a m u s i q / music in the console / YANDEX · … · v0.1.0`.
Код разложен по `src/app.rs`, `src/ui/`, `src/audio/`, `src/yandex/`; карта
исходников — в `README.md`.

## Чего в репозитории больше нет

Первый скелет (`src/main.rs` на 218 строк: три колонки, «Not playing», список
команд), старая сборка `dist/yamusiq` и вся прежняя 16-коммитная история
удалены. **Если перед работой над внешним видом вы ищете «прошлую версию» — её
нет, и брать за образец что-то из старых заметок или скриншотов не нужно:
эталон — текущий `master`.**

Правило: внешний вид сверять с `src/ui/` в `master` и с запуском
`cargo run --release`, а не с воспоминаниями о первоначальной заглушке.

## Сборка и запуск

```sh
cargo run --release      # плеер (первый запуск — вход в Яндекс)
cargo run -- --login     # сменить аккаунт
cargo run -- --help      # остальные ключи
cargo test               # тесты
```

Нужен `ffmpeg` в `PATH` (`brew install ffmpeg`) для воспроизведения. Токен
Яндекса: `~/.config/yamusiq/token` (права 600). Конфиг —
`~/.config/yamusiq/config.json`, сессия — `~/.config/yamusiq/session.json`,
библиотека — `~/Library/yamusiq`. Токен **никогда** не выводить в чат, в логи
и не коммитить.

## GUI

GUI-попытки (Vue + Tauri, обёртки `.app`) отменены по решению пользователя и
удалены. Возвращаться к ним только по явной просьбе и только на основе
текущего `src/ui/`.
